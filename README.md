# 🍕 Sistema de Pizzaria

Projeto desenvolvido com foco na prática de **HTML5** e **CSS3**, simulando a interface de um sistema de pizzaria. O objetivo foi criar uma experiência visual completa contendo páginas essenciais para navegação e interação do usuário, sem a utilização de JavaScript ou frameworks.

## 📋 Sobre o Projeto

Este projeto consiste em uma aplicação front-end para uma pizzaria, desenvolvida exclusivamente com HTML e CSS. A aplicação conta com:

* Landing Page institucional;
* Tela de Login;
* Tela de Cadastro (Criar Conta);
* Página de Cardápio;
* Layout responsivo para diferentes dispositivos.

Durante o desenvolvimento foram aplicados conceitos fundamentais de estruturação, estilização e organização de interfaces modernas.

## 📚 Conceitos Aplicados

### HTML Semântico

Foram utilizadas tags semânticas para melhorar a organização do código e a acessibilidade da aplicação.

Exemplos:

```html
<header>
<nav>
<main>
<section>
<article>
<footer>
```

### CSS Flexbox

Utilizado para alinhamento e distribuição de elementos em diversos componentes da interface.

Aplicações:

* Menus de navegação;
* Formulários;
* Alinhamento de botões;
* Estruturação de seções.

### CSS Grid Layout

Empregado principalmente para organizar conteúdos em formato de grade.

Aplicações:

* Exibição dos itens do cardápio;
* Distribuição de cards;
* Layouts responsivos.

### Responsividade

O projeto foi adaptado para diferentes tamanhos de tela utilizando:

* Media Queries;
* Flexbox;
* CSS Grid;
* Unidades relativas.

Garantindo boa experiência em:

* Smartphones 📱
* Tablets 📲
* Desktops 💻

### Variáveis CSS

Foram utilizadas variáveis para padronizar cores, espaçamentos e facilitar a manutenção do código.

Exemplo:

```css
:root {
  --cor-primaria: #ff6b35;
  --cor-secundaria: #2c2c2c;
  --cor-texto: #ffffff;
}
```

### Organização do CSS

A estilização foi desenvolvida buscando:

* Reutilização de classes;
* Código limpo;
* Fácil manutenção;
* Padronização visual.
